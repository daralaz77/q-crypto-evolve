Una IA escribió criptografía. ¿Cómo se comprueba que no se equivocó?

Este recorrido muestra, con trazas reales grabadas, cómo un laboratorio de criptografía poscuántica entrega una clave y cómo sus propias pruebas atrapan fallos.

Simulación de laboratorio. El equipo QKD es un emulador, no hay física cuántica, y ninguna persona ajena al proyecto ha revisado el código. No lo uses para proteger datos reales.

1. El recorrido de una clave

Cuatro pasos. Cada uno muestra la línea exacta que imprimió el programa y qué significa, en lenguaje normal.

2. Cómo atrapa un fallo

Se introduce un fallo a propósito en el código del protocolo y se mira si el sistema lo nota. Estas son las comprobaciones reales de esa demostración.

    Lo importante: tras reparar, el código cambió, así que las firmas de la versión anterior dejan de valer (comprobación 9). Una firma humana solo cubre el código exacto que se firmó.
