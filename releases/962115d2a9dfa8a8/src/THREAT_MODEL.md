# Modelo de amenazas — Q-Crypto Evolve (laboratorio v0.3)

Regla: una amenaza solo figura como **mitigada** si hay al menos una prueba que falla cuando el control se rompe.
`tests/test_threat_model.py` verifica que cada prueba citada existe. Las que fallan al romper el control se
midieron con la prueba de mutación (`python -m qce mutate`). Lo que no tiene prueba se declara **SIN PRUEBA**.

Activos: A1 confidencialidad/integridad de sesiones · A2 claves privadas y semillas · A3 libro de incidentes y registros ·
A4 integridad del código y de las puertas de verificación · A5 claves QKD.
